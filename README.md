## ⚡ Quick Start

```bash
# Download the pack
curl -L https://github.com/shelly/ai-dev-workflow-pack/releases/latest/download/pack.tar.gz | tar -xz

# Or just copy a template
cp templates/nextjs-sqlite/CLAUDE.md /your/project/CLAUDE.md

# Run a security audit
python3 commands/security-audit.py /your/project --ci

# Start coding with AI superpowers
claude
```
